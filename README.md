## 1. Назначение и цель проекта

Цель работы — трансформация статического адаптивного веб-сайта интернет-магазина (КР №3) в полноценный интерактивный веб-интерфейс с использованием чистого JavaScript (ES6+), стандартного DOM API, событийной модели и клиентского хранилища без использования сторонних фреймворков и библиотек (таких как React, Vue, jQuery или Lodash).

Проект строго соответствует всем требованиям методических указаний:
- Отсутствие блокирующих системных окон `alert()`, `confirm()`, `prompt()` — все уведомления и ошибки выводятся непосредственно в DOM-дерево.
- Полная безопасность вывода пользовательских и динамических данных через `textContent` и `createElement` (защита от XSS-уязвимостей).
- Модульная архитектура скриптов с разделением ответственности по отдельным файлам.
- Полная синхронизация состояния корзины через `localStorage`.

## 3. Описание JavaScript-модулей

### `js/data.js`
Хранит массив `products` из 10 детально описанных товаров магазина акустики и аудиотехники «SoundPulse». Каждый объект содержит поля:
- `id` (число): уникальный идентификатор;
- `title` (строка): наименование товара;
- `category` (строка): категория (`headphones`, `speakers`, `amplifiers`, `accessories`);
- `price` (число): актуальная стоимость в рублях;
- `oldPrice` (число | null): прежняя цена для товаров со скидкой;
- `rating` (число): оценка покупателей (от 1 до 5);
- `reviewsCount` (число): количество отзывов;
- `badge` (строка | null): бейдж («Хит», «Новинка», «Скидка»);
- `image` (строка): относительный путь к изображению;
- `description` (строка): подробное описание характеристик;
- `isAvailable` (булево): флаг наличия на складе.

### `js/catalog.js`
Отвечает за рендеринг и интерактивность страницы каталога:
- **Генерация карточек:** карточки создаются через `document.createElement()`, стилизуются методами `classList.add()`, а текстовые данные записываются строго через `.textContent`.
- **Живой поиск:** обработчик события `input` на поле поиска ищет совпадения по названию и описанию товара (регистронезависимо с нормализацией `.toLowerCase().trim()`).
- **Фильтрация по категориям:** событие `change` на выпадающем списке категорий фильтрует массив через `Array.prototype.filter()`.
- **Сортировка:** событие `change` на селекторе сортировки сортирует копию массива (`[...products]`) по цене (возрастание/убывание) и алфавиту (А–Я, Я–А) с помощью `localeCompare`.
- **Индикатор количества:** динамически выводит «Найдено товаров: X из Y».
- **Пустое состояние (Empty State):** при отсутствии результатов фильтрации выводится информационный блок с кнопкой «Сбросить фильтры».

### `js/cart.js`
Реализует полный цикл работы с покупательской корзиной:
- **Хранение в `localStorage`:** ключ `soundpulse_cart` сохраняет состояние между перезагрузками страницы и переходами.
- **Методы:** `addToCart(productId, quantity)`, `removeFromCart(productId)`, `updateQuantity(productId, delta)`, `clearCart()`.
- **Расчёт стоимости:** итоговые суммы рассчитываются методом `Array.prototype.reduce()`.
- **Промокод:** поддержка промокода `SOUND2026` со скидкой 10% (сохраняется в `soundpulse_promo`).
- **Синхронизация счетчика:** функция `syncCartBadge()` обновляет бейдж количества в шапке на всех 6 страницах сайта.
- **Всплывающее уведомление (Toast):** при добавлении товара в корзину на 3 секунды появляется анимированное уведомление с кнопкой перехода в корзину.
- **Интерактивный рендеринг корзины:** генерация списка позиций с кнопками «+», «−», «Удалить», отображение итоговой суммы, скидки и динамической формы промокода.

### `js/validation.js`
Клиентская валидация форм оформления заказа (`order.html`) и обратной связи (`contacts.html`):
- Отключение браузерных дефолтных всплывашек через атрибут `novalidate`.
- Валидация полей:
  - Имя: не менее 2 символов, отсутствие цифр.
  - Email: соответствие регулярному выражению RFC-формата (`/^[^\s@]+@[^\s@]+\.[^\s@]+$/`).
  - Телефон: проверка наличия не менее 10 цифр.
  - Согласие на обработку данных: обязательный чекбокс `checked`.
- **Живая валидация:** события `input` и `blur` снимают ошибки и добавляют класс `.is-valid`.
- **Вывод ошибок в DOM:** создание и добавление элементов `<span class="form-field-error">` без применения `alert()`.
- **Баннер успешной отправки:** после успешной валидации выводится информационный блок `.form-success-banner`, форма очищается, а корзина обнуляется.

### `js/modal.js`
Управление модальным окном быстрого заказа товара:
- Использование нативного HTML5 элемента `<dialog>` и методов `.showModal()` и `.close()`.
- Доступность: автоматический фокус на первом поле, блокировка прокрутки фона, закрытие клавишей `Escape` и кликом по оверлею (backdrop).
- Встроенная валидация полей модального окна с выводом ошибок в DOM без `alert()`.

### `js/main.js`
Главный оркестратор общих интерфейсных сценариев:
- Мобильное меню-гамбургер: переключение классов, управление атрибутом доступности `aria-expanded`, поддержка закрытия по клавише `Escape`.
- Инициализация кнопок покупки на странице отдельного товара (`product.html`).
- Глобальная синхронизация бейджа корзины при загрузке документа (`DOMContentLoaded`).

## 4. Демонстрация функционала и безопасности

### 1. Безопасность вывода данных (XSS-Free)
Все текстовые поля формируются следующим образом:
```javascript
const title = document.createElement('h3');
title.className = 'catalog-card-title';
title.textContent = product.title; // Защита от XSS — браузер интерпретирует как текст
```

### 2. Чистая фильтрация и сортировка без мутации исходных данных
```javascript
let filtered = products.filter(p => matchesFilter(p));
const sorted = [...filtered].sort((a, b) => a.price - b.price); // Копия массива
```

### 3. Валидация без alert()
```javascript
function showError(input, message) {
  input.classList.add('is-invalid');
  const errorEl = document.createElement('span');
  errorEl.className = 'form-field-error';
  errorEl.textContent = message;
  input.parentElement.append(errorEl);
}
```

## 5. Выполненные самостоятельные улучшения (на максимальный балл 8.0)

В соответствии с критериями оценивания (дополнительные 4.0 балла за инициативу и качество):
1. **Полноценная страница корзины (`cart.html`)**: динамическое добавление, редактирование количества, мгновенный пересчет стоимости с помощью `reduce()`, удаление товаров и полная синхронизация через `localStorage`.
2. **Система промокодов**: валидация и применение промокода `SOUND2026` с 10% скидкой, сохранение промокода и анимация скидки в итоговом чеке.
3. **Анимированный Toast-нотификатор**: всплывающее окно при добавлении в корзину с кнопкой перехода в корзину.
4. **Интерактивное модальное окно на `<dialog>`**: быстрый заказ в 1 клик с trap-focus, закрытием по Esc и оверлею.
5. **Живая валидация полей ввода (`input`/`blur`)**: подсветка валидных (`.is-valid`) и ошибочных (`.is-invalid`) полей с понятными подсказками.
6. **Кнопка сброса в Empty State**: при отсутствии совпадений в поиске пользователь в 1 клик возвращает полный каталог.
7. **Полная адаптивность и 0px горизонтального скролла**: сайт протестирован на разрешениях 360px, 430px, 768px, 1024px, 1440px.
8. **0 ошибок в консоли**: весь код защищен проверками существования элементов в DOM (`if (!el) return`).

## 6. Инструкция по локальному запуску

   ```bash
   git clone https://github.com/bekirand/kr4-js-shop.git
   cd kr4-js-shop
   ```

   - С использованием расширения **Live Server** в VS Code, либо

     ```bash
     npx serve .
     # или
     python -m http.server 8000
     ```
